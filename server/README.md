# OrbitWatch Server Blueprint

This folder is intentionally a placeholder for the MERN backend.

Recommended structure:

```text
server/
├── src/
│   ├── controllers/
│   ├── routes/
│   ├── services/
│   │   └── providers/
│   ├── models/
│   ├── middleware/
│   └── app.js
└── package.json
```

The backend should own external satellite-provider API keys and cache results.
